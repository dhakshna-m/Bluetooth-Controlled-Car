# Bluetooth-Controlled Car

## Project Overview
This is an academic project based on a Bluetooth-controlled car. It uses wireless communication to control the movement of a car through a mobile phone.

## Working Principle
1. The mobile phone sends commands through Bluetooth.
2. The Bluetooth module receives the commands.
3. The Arduino processes the commands.
4. The motor driver controls the DC motors.
5. The car moves according to the received commands.

## Components
- Arduino Uno (if used)
- Bluetooth module (HC-05, if used)
- Motor driver (if used)
- DC motors
- Car chassis
- Battery
- Connecting wires
